# ClassLink (JavaScript / Node.js)
1. Install Node.js 18+ (https://nodejs.org)
2. In this folder run: `node server.js`
3. Open http://localhost:3000 (same Wi-Fi: http://YOUR-PC-IP:3000)
Everyone who opens the link shares the same classroom in real time. Data is saved in data.json.
To use over the internet, deploy this folder to Render, Railway or any Node host.
